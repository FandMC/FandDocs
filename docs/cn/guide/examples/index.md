# 示例插件

这里放一些可以直接照着写的小插件。每个示例只解决一个明确问题，代码尽量完整，不把重点藏在“省略业务逻辑”里。

这些示例默认你已经用官方 Gradle 插件创建了工程，并且 `fand-plugin.json` 里的 `mainClass` 指向示例类。

## 读示例时注意什么

- 示例代码优先使用 `context.*` 里的插件作用域服务。
- 原版物品使用数据生成的 `ItemKey`，不要手写 `"minecraft:xxx"` 物品 id。
- 会改世界、玩家、背包的代码都放在主线程语义里；耗时 I/O 再拆到异步任务。
- 示例为了清晰会省掉部分生产级策略，例如完整权限体系、配置文件热加载、多语言消息。

## 真实插件还要补什么

- 给公开命令声明权限节点。
- 把半径、冷却、消息等可变内容放进配置文件。
- 对玩家输入做完整校验。
- 对数据库、网络请求、复杂计算使用调度器拆分线程。
